### Первый незавершённый чекбокс ROADMAP.md (строка 18)

- [ ] После подтверждения спавна: единый Java runtime/порты к движку, автономная популяция,
  сброс состояния при смене мира, Knox только как необязательный адаптер.

Причина, почему это не закрыто: подтверждён только факт спавна одного тела
(debug#1, active=1/bodies=1, registered/squareMember/model=true); единого Java runtime
и портов к движку нет, автономная популяция и сброс состояния при смене мира не проверены,
Knox по-прежнему используется как адаптер. Проверка видимости/следования/FPS
(следующий чекбокс, строка 20) тоже остаётся открытой.

### Запреты, обязательные для этого пункта

- Не менять скрипты запуска игры (`tools/launch_dev.sh`, `tools/launch_game.sh`,
  `tools/launch_test.sh`, `dev_launch.py`) без прямой просьбы человека.
- Не запускать игру вне `tools/launch_dev.sh`.
- Не ставить статус `blocked` на основании проверки `/dev/dri`, `nvidia-smi` или `glxinfo`
  в обычной песочнице (они отсутствуют по design). Дисплей — `:1`.
